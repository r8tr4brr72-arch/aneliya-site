# reels-montage: скилл Claude Code для монтажа рилсов

Берёт сырое вертикальное видео, где вы говорите в камеру, и делает готовый рилс:
- вырезает паузы, «эээ» и неудачные дубли;
- добавляет субтитры, где произносимое слово подсвечено оранжевым, а ключевые слова написаны ЗАГЛАВНЫМИ;
- ставит оранжевые плашки-заголовки по блокам («Лайфхак №1…») и белые карточки с сутью;
- чередует зум на склейках, может делать чёрно-белые вставки;
- добавляет звуки на появление графики и фоновую музыку, которая приглушается, когда вы говорите;
- делает воронку: полоска внизу «Напиши «САЙТ» в комментариях» и финальная карточка с кодовым словом;
- выдаёт файл 1080×1920, 30 fps, громкость −14 LUFS, как рекомендует Instagram.

Всё работает локально на вашем компьютере. Распознавание речи (Whisper) тоже локальное и бесплатное.

## Установка (Windows, один раз, ~10 минут)

1. Скачайте папку `reels-montage` целиком.
2. Правый клик по `setup.ps1` → «Выполнить с помощью PowerShell».
   Скрипт поставит Python (если его нет), FFmpeg и библиотеки, а потом скопирует скилл в
   `%USERPROFILE%\.claude\skills\reels-montage`.
3. Перезапустите терминал и Claude Code.

## Как пользоваться

Откройте Claude Code в папке с видео и напишите обычными словами, например:

> Смонтируй рилс из `лайфхаки_2.mp4`. Кодовое слово САЙТ, в конце пришлю инструкцию, как сделать сайт.

Claude расшифрует речь, соберёт план монтажа, сделает черновик, сам посмотрит кадры, поправит и отрендерит финал
`лайфхаки_2_REELS.mp4`. Правки даёте текстом: «убери кусок про…», «плашку №2 назови иначе», «добавь музыку music.mp3».

Чтобы смонтировать в стиле понравившегося рилса, пришлите ссылку (если у Claude подключён инструмент для просмотра видео) или 3–4 скриншота.

## Сколько это занимает времени

На обычном ноутбуке без видеокарты исходник на 5 минут обрабатывается примерно за 5–15 минут:
расшифровка, черновик, финальный рендер. Плюс 1–2 круга правок.

## Чего скилл не делает

- Сложный моушн-дизайн (анимированные интерфейсы, графики, 3D): только шаблонные плашки и карточки.
- Не переставляет куски местами и не исправляет плохой звук или свет.
- Не отвечает людям в директ. Чтобы инструкция по слову «САЙТ» отправлялась автоматически, нужна отдельная автоворонка в Instagram (например, ManyChat).

Шрифт Inter распространяется по лицензии SIL OFL 1.1 (`assets/fonts/OFL.txt`).
