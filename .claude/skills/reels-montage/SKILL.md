# Монтаж Reels из сырого видео

> Перед монтажом прочитай `../video-director/LESSONS.md` и рецепты в `../video-director/recipes/` (например, `audio-review` для отзывов). Утверждённые правки закрепляй по `../video-director/EVOLUTION.md`.

Пайплайн: **расшифровка → план монтажа (это делаешь ты, Claude) → рендер → проверка кадров → финальный рендер**.
Скрипты лежат в папке `scripts/` рядом с этим файлом. Дальше `SKILL` = путь к папке этого скилла
(обычно `%USERPROFILE%\.claude\skills\reels-montage`). На Windows запускай `python` (если не найден — `py`).

Всё рабочее складывается в папку `<имя видео>_montage\` рядом с видео. Результат: `<имя видео>_REELS.mp4`.

## 0. Проверка окружения (один раз за сессию)

```
ffmpeg -version
python -c "import faster_whisper, PIL, numpy; print('ok')"
```
Если чего-то нет — запусти `SKILL\setup.ps1` (PowerShell) или вручную:
`winget install Gyan.FFmpeg` и `python -m pip install -r SKILL\requirements.txt`. После установки FFmpeg терминал нужно перезапустить.

## 1. Расшифровка

```
python SKILL/scripts/transcribe.py "ПУТЬ\к\видео.mp4" --model small
```
- `small` — быстро (на обычном ноутбуке ≈ 0.3–1× длины видео). Если в субтитрах много ошибок — `--model medium`.
- В `--prompt` можно передать термины из видео (названия сервисов, имена), чтобы они распознались правильно.
- Получишь `transcript.txt` (фразы с номерами и таймкодами) и `words.json`.

## 2. Черновой план

```
python SKILL/scripts/draft_plan.py "видео.mp4" --style terra --keyword САЙТ
```
Скрипт сам убирает паузы > 0.45 с и «эээ/ммм», ставит зумы на склейках. `--keyword` — кодовое слово воронки
(спроси у пользователя, если не сказано; по умолчанию САЙТ).

## 3. Редактура плана — главная часть, делаешь ты

Прочитай `transcript.txt` и `plan.json` и отредактируй `plan.json` по правилам ниже. **Все времена `at` — в секундах исходного видео** (как в transcript.txt), скрипт сам пересчитает их после нарезки.

**Дубли и мусор.** Если фраза повторяется (человек сбился и начал заново) — оставь последний удачный вариант, остальные куски удали из `keep`. Удаляй оговорки, «так, сейчас ещё раз», обращения к оператору, длинные вступления («всем привет, меня зовут…» — только если это не фирменная фишка автора). Можно подрезать `start`/`end` у куска, чтобы отрезать начало/конец фразы — опирайся на тайминги слов в `words.json`.

**Хук.** Первые 1–2 секунды решают всё. Если сильная фраза («3 фишки ИИ, которые экономят мне 10 часов в неделю») прозвучала не в начале — переставлять куски нельзя (keep сортируется по времени), но можно вырезать слабое начало, чтобы видео стартовало с сильной фразы. Скажи пользователю, если хук слабый, и предложи перезаписать первую фразу.

**Длина.** Цель 30–60 с. Если получается больше 75 с — предложи пользователю, что ещё вырезать, или разбить на две части.

**Поля плана:**
- `keep[]`: `{start, end, text, zoom, bw}` — куски, которые остаются. `zoom: true` — приближение (чередуй на склейках, чтобы скрыть джамп-кат). `bw: true` — ч/б (для «раньше было плохо», боли, контраста).
- `headers[]`: `{at, text, dur?}` — оранжевая плашка сверху. Держится до следующей плашки. Ставь одну на каждый смысловой блок: хук-тема, «Лайфхак №1: …», «Лайфхак №2: …». 2–6 слов, без точки.
- `cards[]`: `{at, dur, title, text}` — белая карточка в верхней половине на 2–3 с. Для сути лайфхака / промпта / цифры. title ≤ 4 слов, text ≤ 12 слов. Не чаще одной карточки на 5–7 с.
- `highlight[]`: начала ключевых слов (`"нейросет"` поймает «нейросети», «нейросетью»). Они в субтитрах будут ЗАГЛАВНЫМИ и оранжевыми. 1 ключевое слово на 1–2 фразы, не больше — иначе выделение теряет смысл.
- `replace{}`: исправления распознавания для субтитров: `{"клод": "Claude", "чат": "ChatGPT"}` (ключ — слово, как его распознал Whisper, без учёта регистра и знаков).
- `cta`: воронка. `keyword` — кодовое слово, `bar_text` — полоска внизу (появляется с `bar_from` секунды готового видео), `title`/`subtitle` — финальная карточка на последние `final_seconds` с. Финальная карточка должна совпадать с моментом, когда человек сам произносит призыв; если призыва в речи нет — оставь 3–4 с, но предупреди пользователя, что лучше записать устный CTA. `hide_subs_on_final: true` — убрать субтитры под финальной карточкой.
- `blur[]`: `{x, y, w, h, from?, to?, mode?, strength?}` — размыть область кадра (координаты готового кадра 1080×1920; найди их по кадру из `snapshot.py`). `mode: "cover"` — закрыть сплошной плашкой `color`. Для отзывов-скринов переписки обязательно закрывай: имя и аватар собеседника в шапке, номер телефона, аватарки в пузырях, счётчик времени и «волну» голосовых (после нарезки он скачет). Проверь по кадрам, что ничего не просвечивает в начале, середине и конце.
- `music`: путь к mp3 (относительно видео) или `null`. Музыка автоматически приглушается под голос.
- `sfx`: `true/false` — звуки на появление плашек и карточек.
- `style`: **по умолчанию `"terra"`** — минимализм в терракоте бренда (#B5763C): коучинг, отзывы, всё кроме линий Гейша и Лила. Для игры «Лила» — **`"lila"`** (приглушённый оливковый #6B7046). Для линии Гейша — **`"geisha"`** (вино/пергамент/золото). Оба: субтитры тонким курсивом Noto Serif без «караоке», мягкое затемнение под субтитрами, плашки мелким капсом Montserrat с разрядкой и тонкой линией, полупрозрачные панели. `"orange"` и `"beige"` — старые стили по чужим рилсам, только если об этом попросят.
- `stickers[]`: `{at, emoji, x, y, size, dur}` — эмодзи, всплывающее поверх видео (x, y — доли экрана, по умолчанию 0.78 / 0.30, справа от лица). 1 стикер на 5–10 с, только на эмоциональных словах.
- `scenes[]`: анимированные вставки — см. следующий раздел. Это главный инструмент «дорогого» монтажа.

## 3а. Сцены-вставки (делаешь сам, не дожидаясь просьбы)

Пользователь хочет «закинуть видео и получить готовое со вставками». Поэтому **по умолчанию сам придумывай вставки** под смысл речи, а не только нарезку. Сцена = промежуток времени, в который на экране собирается визуальная мысль.

```json
{"at": 12.3, "until": 18.0, "layout": "split", "items": [
  {"type": "pill", "at": 12.5, "emoji": "💰", "text": "$500 000", "variant": "light"},
  {"type": "pill", "at": 13.1, "emoji": "📈", "text": "повышение зарплаты"},
  {"type": "strike", "at": 15.0}
]}
```
- `layout`: `"split"` — видео уезжает в верхнюю половину, снизу панель цвета `panel_bg`, субтитры на стыке (главный режим стиля beige); `"overlay"` — видео на весь экран, элементы в верхней части поверх него.
- `until` — конец сцены (по умолчанию — начало следующей сцены). Между сценами видео снова на весь экран — **чередуй**: 2–4 с говорящей головы, потом сцена 3–8 с. Первые 1.5–2 с и последние 2–3 с — без панели (лицо = доверие).
- Время `at` у каждого элемента = момент, когда это слово **произносится** (бери из words.json) — элемент появляется синхронно с речью.

Типы элементов (`items[]`), каждый появляется с пружинной анимацией и звуком:
- `pill` — «таблетка»: `emoji`, `text` (1–3 слова), `variant`: `"dark"` (эмодзи слева + тёмная таблетка) или `"light"` (белая карточка). Для перечислений — по одной на пункт, столбиком.
- `row` — несколько таблеток в строку: `{"type":"row","items":[{"emoji":"🧠","text":"мысли","at":..}, ...]}` (переносится сама).
- `title` — крупный текст/число с засечками: `text`, `size`. Для цифр, тезиса-хука, «главного слова».
- `text` — фраза помельче курсивом.
- `counter` — счётчик-«накрутка»: `from`, `to`, `prefix` ("$"), `suffix` (" ₸", "%"), `decimals`. Для любых денег и процентов в речи.
- `flow` — схема со стрелками: `steps: [{"text":"ТЫ","at":..},{"text":"состояние","at":..}]`. Для причинно-следственных связей «А → Б → В». Не больше 3 шагов, слова короткие.
- `bars` — сравнение столбиками: `bars: [{"label":"деньги","emoji":"💵","value":0.3},{"label":"стресс","emoji":"🤯","value":1.0,"at":..}]` (value 0..1). Для «мало vs много», «до vs после».
- `card` — карточка-документ/приложение: `emoji`, `title`, `text`, `lines` (серые строки-заглушки). Для упоминаний сервисов, документов, приложений, чатов («Налоговая — декларация», «ChatGPT — новый чат»).
- `emoji` — одно крупное эмодзи (`size` 150–220).
- `strike` — зачёркивает все предыдущие элементы сцены (или `targets: [0, 2]` — по номерам). Для «это не работает», «забудьте про…».

Правила хорошей вставки:
1. Вставка **иллюстрирует** слово, а не повторяет субтитры: перечисление → таблетки; цифра → счётчик; противопоставление → столбики или зачёркивание; процесс → flow; упоминание сервиса → card.
2. Эмодзи — одно, точное по смыслу, однокодовое (💰 📈 🧠 🤯 ✅ ❌ 💡 📱 🔥 ⏰ 🎯 💸 🧘 📋). Без флагов, без составных эмодзи с кожей/ZWJ.
3. Текст в таблетке ≤ 3 слов, в title ≤ 5 слов. Цифры пиши с пробелами: `$1 000 000`.
4. Плотность: в среднем одна сцена на 6–10 с видео; в сцене 1–4 элемента.
5. Стоп-лист: не ставь сцены на шутки и эмоции в лицо (там лучше стикер или ч/б), на финальный призыв (там CTA).

## 3б. Хук и предложения пользователю

- Сам поставь `headers[0]` на первые ~2 с — короткий хук-заголовок (≤ 7 слов), который обостряет первую фразу (интрига, цифра, «никогда/всегда», спор с распространённым мнением). В стиле beige он рисуется крупными белыми буквами с засечками.
- В отчёте предложи **3 альтернативных хука** (заголовок + первая фраза для перезаписи), если считаешь исходный слабым.
- Если в речи нет устного призыва к кодовому слову — скажи об этом и предложи текст призыва для дозаписи (5–7 с).

## 4. Черновой рендер и проверка

```
python SKILL/scripts/render.py "видео.mp4" --draft
python SKILL/scripts/snapshot.py "видео_DRAFT.mp4" --n 8
```
`--times` задаётся во времени готового видео; чтобы проверить сцену, переведи её `at` через пропорцию по keep или просто сделай `--n 12`. На черновике (`--draft`) на бежевой панели бывают бледные «следы» прошлых элементов — это сжатие черновика, в финале их нет.

**Обязательно открой получившийся `*_frames.png` (Read) и посмотри глазами**: не перекрывают ли карточки лицо слишком долго, читаются ли плашки, не залезает ли текст за края, правильные ли слова в субтитрах. Для точечной проверки — `--times 3.5 12 20`. Исправь план и перерендерь (повторный рендер быстрый: нетронутые куски берутся из кэша).

## 5. Финальный рендер

```
python SKILL/scripts/render.py "видео.mp4"
```
Отчитайся: путь к файлу, длительность, сколько вырезано, какие лайфхаки/плашки стоят, и честно — что стоит переснять (слабый хук, нет устного призыва, плохой звук).

## Стиль по референсу («сделай как в этом рилсе»)

1. Если доступен инструмент, который смотрит видео по ссылке (например, vidIQ `watch_shortform_content`) — разбери референс: цвета, шрифт, где субтитры, сколько слов на экране, что за плашки, темп склеек. Если нет — попроси скриншоты 3–4 кадров.
2. Создай `styles/<имя>.json` — только поля, которые отличаются от `styles/orange.json` (цвета `accent`, `text`, `card_bg`; `sub_y`, `sub_size`, `sub_max_words`, `sub_caps`; `header_y`, `card_y`, `cta_bar_y`; `zoom_punch`; `max_pause` — 0.3 для очень быстрого темпа). Свой шрифт: положи .ttf/.otf в `assets/fonts/` и укажи `font_heavy`/`font_bold`/`font_regular` (имена файлов) и `ass_font` (название шрифта).
3. В `plan.json` поставь `"style": "<имя>"`.
4. Честно скажи, что из референса скилл не повторит: сложный моушн-дизайн (анимированные интерфейсы, графики, 3D) делается только шаблонными карточками.

## Безопасные зоны Instagram (1080×1920)

Сверху ~200 px и снизу ~380 px перекрывает интерфейс, справа ~140 px — кнопки лайков. Плашки по умолчанию на y≈210, полоска CTA на y≈1420, субтитры на y≈1180 — не опускай текст ниже 1560 и не уводи его к правому краю.

## Аудио-отзыв (скрин переписки / голосовое) — формат «аудиоцитата»

Не показывай пёструю переписку на весь экран. Стиль `"terra-audio"`; для игры «Лила» — `"lila-audio"` (оливковый, вуаль `#2A2E1E`); для линии Гейша — `geisha` с теми же полями:
- `"audiogram": {"y": 640, "label": "голосовое участницы"}` — своя минималистичная плашка голосового с живой волной по громкости голоса (личных данных на ней нет, вырезать плашку из скрина не нужно).
- Фон, вариант 1 — размытая переписка: `"blur": [{"x":0,"y":0,"w":1080,"h":1920,"strength":38}]` + `"veil": {"color":"#3A2318","alpha":0.55}`.
- Фон, вариант 2 — своё атмосферное видео (поездка, природа, бэкстейдж игры): `"background": {"video": "фон.mp4", "blur": 0}` + `"veil": {"color":"#2A1A14","alpha":0.45}`. Голос берётся из записи отзыва, картинка — из фона (фон зацикливается, если короче).
- Все `keep[].zoom` = false (скачки приближения на неподвижной картинке выглядят как сбой). `headers`: «Отзыв после игры «…»» на всё видео. Призыв — только финальная карточка, `bar_text` пустой.
- Суть важнее полноты: оставь 3–5 фраз «было → что случилось на игре → что изменилось», 20–35 секунд. Вырезай «вот», «как бы», незаконченные фразы — субтитры крупные, каждое слово на виду.
