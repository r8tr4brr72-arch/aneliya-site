# Рецепт: аудио-отзыв «аудиоцитата»

Статус: утверждён 2026-11-27 (отзыв об игре «Лила»).

## Когда
Отзыв голосовым сообщением: запись экрана переписки, голосовое, аудио.

## Шаги
1. Положить запись в папку проекта (`videos/`), транскрибировать (`reels-montage/scripts/transcribe.py`), черновой план (`draft_plan.py --style lila-audio` для Лилы / `terra-audio` для коучинга / `geisha` для Гейши).
2. Отобрать 3–5 фраз по схеме «было → что случилось на игре → что изменилось», 20–35 с. Каждая цитата — законченная мысль; «вот», «как бы», недоговорённое — вырезать.
3. Заполнить план по шаблону `plan.template.json`: фон — размытая переписка (`blur` на весь кадр + `veil`) или своё атмосферное видео (`background.video`), `audiogram`, заголовок «Отзыв после игры «…»», финальная карточка с кодовым словом, `bar_text` пустой, все `zoom` = false.
4. Рендер, кадры начала/середины/конца: ничего личного не просвечивает, цитаты целые, карточка не перекрыта субтитрами.
5. Перед публикацией — письменное согласие участницы на голос.
