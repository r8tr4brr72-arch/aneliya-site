# Рецепт: квиз-серия в сторис (линия «Гейша»)

Статус: утверждён 2026-11-27, опубликован.

## Когда
Ежедневный/регулярный квиз о мире гейш в сторис.

## Шаги
1. Вопрос — из «Банка вопросов квиза» в контент-плане (Claude Docs «Анелия: контент-план, тексты и сценарии»). Вышедшие зачёркнуты, «не брать» — не предлагать. Формулировку пересказать своими словами, 4 варианта для стикера (правильный + 3 правдоподобных).
2. Акварель-метафора ответа — p5.brush-сцена в `art/geisha-brush/` (есть `index.html` веер+сакура, `shamisen.html`, `willow.html`; новую делать по их образцу, слоями с `brush.render()` после каждого). Рендер этапов → видео `xfade` 1.0 с + 0.6 с, последний кадр 3.5–4 с.
3. Четыре сторис через `scripts/story.py` по шаблонам `examples/0_anons.json … 3_opros.json`:
   - анонс — фото Анелии (вуаль Б, `photo_offset` 380, наезд 0.06, музыка `generate`);
   - вопрос — нейтральная акварель (не показывает ответ), вуаль Б, музыка, место под стикер «Викторина»;
   - ответ — акварель-метафора ответа, **без звука**, слово-ответ Playfair Italic, пояснение 2–3 строки, внизу только «ИГРА «ГЕЙША»»;
   - опрос — «Удалось угадать?», вариант А (всё размыто), **без звука**, варианты «Да, знала / Нет / Теперь буду знать».
4. Проверить кадры (`snapshot.py`): переносы строк по смыслу, текст не наезжает, ответ не виден в вопросе.
5. После публикации — предложить зачеркнуть вопрос в банке с датой.
