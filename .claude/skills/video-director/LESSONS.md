# Уроки: что утверждено и чего не делать

Короткие правила из решений Анелии. Читать перед любой работой с видео. Новое — добавлять сверху раздела.

## Утверждено (делаем так)

- Эстетика — минимализм: курсив с засечками (Noto Serif / Playfair Display Italic), мелкий капс Montserrat с разрядкой, тонкие линии, полупрозрачные панели. Без ярких плашек, «караоке» и громких звуков.
- Цвета по линиям: Гейша — вино/бордовый + пергамент + золото (стиль `geisha`); Лила — приглушённый оливковый `#6B7046` (`lila`, `lila-audio`); коучинг и остальное — терракота `#B5763C` (`terra`).
- Аудио-отзыв — формат «аудиоцитата»: размытый фон (переписка или своё видео) под вуалью, плашка голосового с живой волной, цитаты — законченные мысли до 8 слов в 2 строки, история «было → инсайт → стало», 20–35 с, призыв — одна финальная карточка.
- Квиз в сторис — серия анонс (фото, музыка) → вопрос (рисующаяся акварель, музыка, стикер «Викторина») → ответ (акварель-метафора, без звука, внизу только «ИГРА «ГЕЙША»») → опрос «Удалось угадать?» (без звука). Вопросы — только из «Банка вопросов квиза» в контент-плане, вышедшие зачёркнуты.
- Рисованные вставки — акварель/тушь кодом (p5.brush, Claude Drawing), рисуется слоями, каждый слой «высыхает» (нет мерцания).
- Для нового стиля анимации Анелия присылает 2–5 картинок-примеров (Pinterest), тему в 1–2 фразах, длительность и формат.

## Не делать

- Не использовать оранжевый стиль `orange` (он был по умолчанию и не понравился: «аляписто»). По умолчанию — `terra`, для Гейши — `geisha`, для Лилы — `lila`.
- Не показывать пёструю переписку на весь экран как есть — только размытой под вуалью или вырезанной плашкой поверх фона.
- Не ставить скачки приближения (`zoom`) на неподвижной картинке — выглядит как сбой.
- Не рвать цитаты посередине мысли («что всё-таки остатки у…»); не оставлять «вот», «как бы».
- Не ставить в ответ квиза призыв «Напиши «ГЕЙША»» — «не в тему»; внизу только «ИГРА «ГЕЙША»».
- Не брать вопросы квиза «по памяти» — только из банка; не предлагать вышедшие.
- Не ставить случайные стикеры-эмодзи (✨) в спокойные форматы.
